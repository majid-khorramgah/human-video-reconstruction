# Temporal Structure — Figures

This directory contains the visualizations generated by the
`01_temporal_structure.py` analysis.

The figures provide a visual summary of the temporal organization of
the PhySense-Human dataset.

The dataset contains:

- **500,507 HR frames**
- **547 unique videos**
- **6 dataset shards**
- **499,960 temporal transitions**
- **0 frame-ID gaps**
- **1.000000 global temporal continuity ratio**

These figures are not final experimental results. They are dataset-level
observations that help establish the temporal structure before studying
visual redundancy, motion, and temporal correspondence.

---

## 1. Frames per Video

![Frames per Video](frames_per_video_temporal.png)

### What does this figure show?

This figure shows how many sampled frames are available for each video.

The number of frames varies substantially between videos:

- Minimum: **52 frames**
- Median: **815 frames**
- Mean: **915 frames**
- Maximum: **3,462 frames**

This demonstrates that the dataset contains videos with substantially
different temporal lengths.

### Why does it matter?

The dataset is not simply a collection of independent images.

Each video provides a sequence of temporally ordered observations of the
same scene and subject.

This temporal structure is important for investigating whether information
from neighboring frames can be used for reconstruction or super-resolution.

## 2. Frames per Video Distribution

![Frames per Video Distribution](frames_per_video_temporal.png)

### What does this figure show?

This visualization highlights the distribution of temporal sequence lengths
across the 547 videos.

Most videos contain hundreds of sampled frames, while some videos contain
substantially longer sequences.

### Research relevance

Long sequences provide the opportunity to study how visual information
changes over time rather than treating every frame as an isolated sample.

However, sequence length alone does not tell us whether neighboring frames
contain redundant or complementary information.

This motivates the next analysis:

`02_frame_similarity.py`

## 3. Estimated Video Duration

![Estimated Video Duration](estimated_video_duration.png)

### What does this figure show?

The figure estimates the temporal duration represented by each video based
on the frame sampling structure.

Because frames were sampled at approximately one-second intervals, the
number of sampled frames provides an estimate of the temporal coverage of
each video.

### Why is this useful?

The figure gives an intuitive view of how much temporal information is
available per video.

A long sequence potentially provides multiple observations of:

- human pose
- body motion
- clothing deformation
- viewpoint changes
- illumination changes
- interactions between the subject and clothing

These changes may provide information that is unavailable from a single
frame.

## 4. Temporal Frame Gap Distribution

![Temporal Frame Gap Distribution](frame_gap_distribution.png)

### What does this figure show?

This figure shows the distribution of frame-ID gaps between consecutive
temporal observations.

The analysis found:

- Temporal transitions: **499,960**
- Adjacent transitions: **499,960**
- Non-adjacent transitions: **0**
- Videos with frame-ID gaps: **0**

Therefore, the extracted sequences are temporally continuous with respect
to their frame IDs.

### Important interpretation

This result establishes **structural temporal continuity**.

It does NOT yet establish visual similarity.

In other words:

> Consecutive frame IDs do not necessarily mean that consecutive images
> contain redundant visual information.

This distinction is important for the research direction.

The next stage therefore measures the actual visual similarity between
neighboring frames.

## 5. Videos per Split

![Videos per Split](videos_per_split_temporal.png)

### What does this figure show?

This figure shows how the 547 videos are distributed across the
training, validation, and test splits.

The split is performed at the video level rather than randomly assigning
individual frames.
